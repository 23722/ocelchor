# `eval_artifacts/`

Workspace for the variant- / conformance-agreement evaluation script (`evaluate_conformance.py`). Split into two subdirectories,

## `input/` — third-party reference data

Read by the evaluation script. Data in this directory was published in Peña et al.
(*Inter-organizational collaborative BPMN 2.0 business process discovery*,
J. Intelligent Information Systems, 2024) and re-distributed here for
reproducibility.

| File pattern | What it is |
|---|---|
| `collog_<dataset>.bpmn` (7 files) | Peña's discovered BPMN choreography models (one per Corradini et al. dataset) |
| `collectivelog_<dataset>_chor.xes` (7 files) | Peña's choreography-level XES logs (one trace per case, one event per choreography task) |

`<dataset>` ∈ { `real1`, `real2`, `real3`, `real4`, `real5`, `healthcare`,
`smartagriculture` }.

## `output/` — script-generated artefacts

Regenerated by `evaluate_conformance.py` from the inputs above plus our
OCEL logs (`xescol2ocelchor/data/output/`) and our per-instance BPMN
models (`ocelchormodel/data/output/`). 

| File pattern | What it is |
|---|---|
| `<dataset>_collog_process.bpmn` (7 files) | Peña's `collog_*.bpmn` rewritten as a plain `<bpmn2:process>` so `pm4py.read_bpmn` can consume it; the diagram section is preserved so the file also opens in standard BPMN editors. Used for alignment-based conformance. |
| `<dataset>_control_flow.xes` (7 files) | Our OCEL projected to a one-trace-per-instance control-flow XES; used for both alignment-based conformance and the variant-agreement comparison |

Safe to delete; the script will rebuild them.
